# تقرير فحص قالب بلوجر — نسخة التطوير 3.9

## التغييرات المنفذة
- توحيد العلامة الافتراضية باسم **البوابة العربية للتقنية**.
- اعتماد عشرة أقسام تقنية شاملة في الصفحة الرئيسية:
  1. شروحات البرامج والتطبيقات.
  2. المشكلات والحلول.
  3. الأدوات الرقمية وتحويل الملفات.
  4. الأمان والخصوصية الرقمية.
  5. المقارنات والترشيحات التقنية.
  6. البرمجة وتطوير المواقع.
  7. الإنتاجية والعمل الرقمي.
  8. الذكاء الاصطناعي.
  9. الأجهزة والهواتف.
  10. الإنترنت والخدمات الرقمية.
- إبراز الأقسام السبعة التي طلبها المستخدم في بداية قائمة التصنيفات.
- تحديث القائمة الرئيسية في قالب Blogger لتعرض الأقسام الأهم، مع بقاء الأقسام العشرة في شبكة التصنيفات.
- تحديث قسم «ابدأ من هنا» ليركز على المشكلات والحلول وشروحات البرامج والأدوات والأمان.
- تحديث المعاينة الثابتة لتعرض عشرة أقسام وعشرة أمثلة مقالات تقنية، دون حذف أو تعديل أي مقالات حقيقية في مدونة Blogger.
- تحديث فحص GitHub Actions للتحقق من وجود الأقسام العشرة ومنع ظهور تصنيفات غير تقنية معروفة.

## ملفات ذات صلة
- القالب: `mawdoo3-inspired-template.xml`
- دليل التخصيص: `CUSTOMIZATION-GUIDE.md`
- قائمة اختبار المدونة التجريبية: `TRIAL-BLOG-TEST-CHECKLIST.md`
- المعاينة: https://ashraf18275.github.io/ashraf/

## ما يجب التحقق منه قبل الاعتماد
- نجاح فحص GitHub Actions بعد هذه التعديلات.
- قبول القالب داخل Blogger على مدونة تجريبية.
- التحقق من أن روابط التسميات تطابق تسميات المقالات المنشورة؛ فالتصنيف الذي لا توجد له مقالات موسومة سيظهر فارغًا.
- مراجعة المظهر على الهاتف والكمبيوتر، واختبار صفحات المقال والتصنيف والبحث.
- التأكد من أن المعاينة المنشورة على GitHub Pages تعرض أحدث commit، لا نسخة مخزنة مؤقتًا.

## حماية المدونة الأساسية
لم يتم تعديل إعدادات Blogger أو المقالات الحقيقية. لم يتم دمج فرع التطوير في `main`. أمثلة المقالات في معاينة GitHub هي محتوى تجريبي فقط. لا يعتمد القالب على المدونة الأساسية قبل اختبار النسخة التجريبية.
