# قالب بلوجر — البوابة العربية للتقنية (نسخة تطوير)

قالب عربي RTL لبوابة تقنية شاملة تركز على الشروحات العملية، المشكلات والحلول، الأدوات الرقمية، والخصوصية. نسخة التطوير منفصلة ولم تُطبّق على المدونة الأساسية.

## الأقسام العشرة
1. شروحات البرامج والتطبيقات.
2. المشكلات والحلول.
3. الأدوات الرقمية وتحويل الملفات.
4. الأمان والخصوصية الرقمية.
5. المقارنات والترشيحات التقنية.
6. البرمجة وتطوير المواقع.
7. الإنتاجية والعمل الرقمي.
8. الذكاء الاصطناعي.
9. الأجهزة والهواتف.
10. الإنترنت والخدمات الرقمية.

الأقسام السبعة الأولى مبرزة في بداية قائمة الأقسام، كما تم تحديث القائمة الرئيسية وبطاقات «ابدأ من هنا». المعاينة تحتوي على أمثلة مقالات تقنية تجريبية، ولا تعني إضافة مقالات إلى مدونة Blogger الحقيقية.

## قبل النشر
يجب اجتياز فحص GitHub Actions ورفع XML إلى مدونة Blogger تجريبية، ثم اختبار الصفحات والروابط على الهاتف والكمبيوتر. القالب يعرض عنوان المدونة ووصفها من إعدادات Blogger. لم يتم تغيير إعدادات المدونة الأساسية، ولم يتم دمج فرع التطوير.
