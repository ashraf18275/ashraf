# قالب بلوجر — البوابة العربية للتقنية (نسخة تطوير)

قالب عربي باتجاه RTL لمدونة تقنية، بواجهة مستوحاة من تنظيم بوابات المعرفة العربية دون نسخ محتواها. النسخة الحالية في فرع تطوير منفصل ولم تُطبّق على المدونة الأساسية.

## محتوى النسخة
- الاسم الظاهر في المعاينة: **البوابة العربية للتقنية**.
- أقسام تقنية فقط: الذكاء الاصطناعي، الأجهزة والهواتف، التطبيقات والبرامج، البرمجة وتطوير الويب، الأمن السيبراني، الأدوات الرقمية وتحويل الملفات، الإنترنت والخدمات الرقمية، والربح والعمل الرقمي.
- قائمة رئيسية قابلة للتعديل عبر أداة LinkList في تخطيط Blogger.
- أدوات HTML قابلة للتعديل للمقدمة والبحث، والموضوعات البارزة، وأقسام التقنية.
- 13 متغيرًا للألوان والخلفيات والعرض والخط.
- مواضع إعلانية قابلة للإدارة من تخطيط Blogger.
- بنية للمقالات والتصنيفات والبحث وترقيم الصفحات.
- قائمة اختبار آمنة على مدونة تجريبية: [TRIAL-BLOG-TEST-CHECKLIST.md](TRIAL-BLOG-TEST-CHECKLIST.md).

## مهم قبل النشر
القالب يستخدم `data:blog.title` و`data:blog.description`، أي إنه يعرض العنوان والوصف المحفوظين في إعدادات Blogger. لضبط العنوان الفعلي إلى **البوابة العربية للتقنية**، افتح **إعدادات Blogger > أساسي > العنوان** واحفظ الاسم هناك. لم يتم تغيير إعدادات Blogger عن بُعد. يجب رفع القالب إلى مدونة تجريبية أولًا؛ فحص XML وحده لا يثبت قبوله أو سلامة العرض في Blogger.
